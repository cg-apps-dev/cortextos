# Deterministic banned-word grep + text normalization (Phase 1/1-V Step 3-5)

The grep is the deterministic gate over the UNION of all extracted on-image / on-screen / spoken text (vision pass A + vision pass B + tesseract OCR; plus whisper audio for video). It fires a FAIL only on an actual banned string, so it does not over-call; three text sources make it hard to miss.

## Term source = the LIVE brain repo (rebuild EVERY run, never freeze)
Pull fresh each run and build the term set from `agents/meta-compliance-agent/references/rules.md` (M-1..M-25) + `scan-rules.md` + `asset-type-scanners.md`. The brain always has the newest codes. The lists below are ILLUSTRATIVE orientation only - the live `rules.md` wins on any conflict. The meta-compliance-agent (running fleet agent) is the authoritative semantic gate for anything you route to it.

## NORMALIZE before grepping (defeat obfuscation)
Apply to the unioned text first:
1. lowercase
2. collapse intra-word spacing and dot/punctuation separators so spaced-out evasions still match: `F L O W E R` and `f.l.o.w.e.r` and `f-l-o-w-e-r` -> `flower`. (Practical approach: also produce a "despaced" copy of the text = remove ALL whitespace + non-alphanumerics, and run the single-token bans against that too.)
3. leet-map: `0->o`, `1->i`, `3->e`, `4->a`, `5->s`, `@->a`, `$->s`.
Run the grep against BOTH the readable normalized text (for multi-word phrases) and the despaced copy (for single-token bans).
**Despaced-copy PITFALL (validated 2026-06-10):** do NOT concatenate across line/element boundaries when building the despaced copy - that creates phantom matches (e.g. "TRY20" + a stray "4" bullet + "20% off" concatenated produced a false "4/20" hit on row 820). Despace only WITHIN a contiguous token/word to catch `f l o w e r`-style intra-word evasion; keep element/line boundaries as separators so distant fragments cannot fuse into a banned string. After any despaced hit, confirm the term actually appears as a real contiguous word in the readable text before failing.

## AMBIGUOUS-SEMANTIC triggers -> UNCLEAR (cannot be called PASS or FAIL with certainty; route to human / meta-compliance)
- **M-4 health-state / relief:** `\brelief\b`, `cure[sd]?`, `treat(s|ment)?`, `anxiety`, `insomnia`, `stress`, `pain`, `feel like yourself`, `feel the difference`.
- **M-6 social-proof NUMBERS:** `\d[\d,]*\s*\+?\s*(customers|reviews)`, `\d(\.\d)?\s*stars?`, `\d+\s*k\b` (customer/review counts), `thousands of`.
- **M-8 press framing:** `\b(CBS|FOX|USA Today|MSNBC|NBC|ABC|Forbes)\b`, `as seen (on|in)`, `as featured` -> UNCLEAR. Note (meta-compliance 2026-06-10): the VERIFIED press set is **CBS / FOX News / MSNBC / USA Today** only; an "as seen on" naming a network NOT in that set (e.g. **NBC**, ABC, Forbes) is an unverified-press FAIL, while a claim citing only the verified set may PASS. The deterministic grep just flags any press logo -> route to vision/meta-compliance for the verified-vs-unverified call.
- **M-20 comparison / superiority:** `better than`, `better \w+ than` (catches "better QUALITY than", "better EFFECT than"), `quality than`, `than (the|my|any|anything|what|i)\b...(getting|got|had|used|tried|before|old|local|shop|dispensar)` (comparative-vs-past testimonials - "way better quality than I was getting before" = the same class Meta DISAPPROVED, proven 2026-06-10 row 94), `stronger than`, `more potent`, `not weak`, `not gas station`, `higher.?quality than`.
- **Gummies (sleep) product blocks** (when scanning the gummies tabs) -> hard-ban side: M-13 sleep-ONSET/duration (`fall asleep`, `sleep through the night`, `drift off`, `wake up rested`, `8 hours`, `natural sleep aid`, `non.?habit.?forming`, `out by \d+`, `asleep by \d+`); M-12 diagnostic-question headline (`can't sleep\??`, `still awake\??`, `trouble sleeping\??`); M-5 side-effect (broaden beyond `no grogginess`/`no morning fog` to: `grog`, `grogginess`, `morning fog`, `zero grog(giness)?`, `without grog` - meta-compliance found these variants on 11 rows 2026-06-10). Wind-down vocabulary (`wind down`, `relax`, `unwind`, `evening ritual`) is ALLOWED. **Do NOT route the bare word `sleep` to UNCLEAR** - sleep gummies say "sleep" on nearly every creative, so a bare-`sleep` trigger floods UNCLEAR (proven 2026-06-10: 163->55 UNCLEAR after removing it); only the M-13 sleep-ONSET/duration phrases above are violations. **Melatonin: UNCLEAR only when NOT in a `no/free/without/zero melatonin` or `melatonin-free` context** (those are the compliant differentiator, not a violation); a bare neutral melatonin mention or melatonin-COMPARISON ("instead of / vs / better than melatonin") -> UNCLEAR (meta-compliance later ruled most melatonin-comparison creatives FAIL on M-12/M-4/M-5).
