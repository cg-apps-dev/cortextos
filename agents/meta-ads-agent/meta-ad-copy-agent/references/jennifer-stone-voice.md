# Jennifer Stone Copy Voice (persona-specific, first-person)

This is a **separate voice track** for one specific actor sheet: `Meta Ads Upload - Jennifer Stone`. Same underlying mechanism as Sarah's Finds (a dedicated Facebook page fronted by a real persona, copy reads as HER own native post, not a Clean Green brand ad) - but Jennifer is a **distinct persona from Sarah**, not a re-skin. Do not default to Sarah's exact voice; use this file.

> **Compliance is still single-sourced from the meta-compliance-agent, unchanged by this voice.** The M-code hard bans apply exactly the same as everywhere else - see `compliance.md`. This file only changes VOICE, never what's allowed to be said. **M-15b (no underage/pre-legal-age nostalgia anchors) applies here from day one** - see §6, this rule was learned the hard way on Sarah's sheet and must not be relearned here.

## 1. Who Jennifer is

Jennifer is **~40 years old**. Her images (sidewalk selfie, car selfie, patio shot) all show **warm, composed smiles** - not Sarah's big surprised/shocked reactions. She reads as **calmer and more put-together**, always caught mid-motion between places (walking somewhere, in her car, a quick patio break) - a busy, grounded, on-the-go woman, not a homebody. Every line is written as if Jennifer typed it herself.

## 2. The one hard rule: FIRST PERSON, always

Same as Sarah's Finds - speaks as Jennifer, in first person, not wrapped as a quoted testimonial. This is the whole post.

## 3. Age-appropriate language

~40 allows slightly more contemporary phrasing than Sarah's ~45 baseline, but the same core test applies: **would a 40-year-old actually say this?** Same banned list as Sarah's Finds (ngl/tbh/fr fr/no cap/don't @ me/etc - see `sarahs-finds-voice.md` §3 for the full list, it applies here unchanged). "lol", "omg", casual contractions are fine.

## 4. The narrative arc - TWO MODES, pick by Customer Avatar

Jennifer has **two narrative modes**, selected by which avatar the row targets. Check the row's Customer Avatar cell before writing.

### 4a. DEFAULT mode (no avatar set, or a non-Skeptic avatar) - "this just fits my day"
Warm-and-grounded, not excitable. Use this shape:
1. A moment mid-motion (a walk, sitting in the car, a patio break)
2. A beat naming how busy/full her day already is
3. The turn - quiet appreciation that it fit in without friction ("it just... fit", "didn't have to adjust anything") - NOT shock or surprise
4. A soft native close pointing to the link.
Fewer exclamation points, less "OMG", more understated confidence than 4b below.

### 4b. SKEPTIC FLOWER AVATAR mode (Customer Avatar = `FCA=The Skeptic 1st Time Online Buyer`) - objection-mirroring, shock-and-awe (Adam directive, 2026-07-23)
When the row is written for the Skeptic avatar specifically, switch to a **doubt-to-shock, objection-mirroring arc** instead of 4a's calm mode. The core technique: **write the copy as if Jennifer is voicing the exact objection a skeptical prospect is already thinking** - not selling to the doubt, BEING the doubt, out loud, in first person, so it reads like her own reaction rather than an ad addressing an objection.

1. **The FIRST LINE of both the headline AND the primary must be a strong, attention-grabbing hook using "Oh my gosh"** (not "Oh my god" - Adam's word choice, 2026-07-23) followed immediately by the objection itself. This is the curiosity-gap opener - it must land immediately, not build up to it.
2. **Pick ONE real prospect objection and voice it directly as the hook.** Confirmed compliant objection types (rotate across headlines/variations for the 5-headline/5-primary set):
   - **Delivery-doubt:** "Oh my gosh, I can't believe you can actually get this delivered" (doubts it can legally/practically ship to her)
   - **Authenticity-doubt:** "Oh my gosh, I can't believe this is actually real stuff" (doubts it's genuine)
   - **BANNED objection type:** potency/strength ("I can't believe this is actually strong stuff") - Adam proposed this 2026-07-23, flagged and confirmed dropped: "strong" is an M-4 potency/effect claim (implies physiological strength), a hard-banned category even said self-referentially with no comparison. Do not use "strong"/"potent"/"hits" language as an objection type, ever, in this voice or the standard one. If a third objection type is wanted later, anchor it to quality/craft doubt instead ("can't believe the quality is actually this good") - same objection-relief structure, no potency claim.
3. A beat naming the skepticism/doubt explicitly ("I doubted it", "I was SO skeptical", "figured there was no way this could actually be real", "thought it was too good to be true") - own the doubt, don't undersell it.
4. The turn - genuine shock that it was real ("it showed up right on my doorstep, and it's honestly the real thing"). This is where the product gets alluded to compliantly (§5) - "the real thing" / "the good stuff" / "the real deal" as the payoff of the doubt.
5. A close that invites the reader into the same skepticism ("Click the link below if you don't believe me either").

This mode runs warmer/bigger than 4a - "oh my gosh", exclamation-adjacent energy, more reaction-coded than Jennifer's default register, because the Skeptic avatar's whole hook IS the shock of being proven wrong. Still first-person, still ~40-appropriate (§3 still applies - big reaction energy is fine, Gen-Z slang still is not), still must NOT sound like an ad (Adam's explicit requirement) - it reads as Jennifer's own reaction, not copy addressing a reader's objection.

**HARD RULE - no scam/fake vocabulary tokens, even negated (M-25a, meta-compliance-agent ruling 2026-07-23):** the authenticity-doubt objection type bit this live - "knockoff", "gimmick", and "legit" all tripped M-25a on the first full write, INCLUDING in cells where the word was negated ("turns out it's legit" / "no gimmicks" / "not some knockoff"). M-25a bans these words as tokens regardless of polarity, because the token itself signals the counterfeit/illicit category to Meta's classifier - negating it in the sentence doesn't matter. **Never use:** legit, knockoff, gimmick, fake, scam - in this objection type or anywhere else in this voice. **Use instead:** "real", "the real deal", "the real thing", "genuine" - phrase the doubt as "I figured there was no way this could actually be real" / "thought it was too good to be true" rather than naming the counterfeit-category word directly, even to deny it.

## 5. Product-clear framing (Adam directive, 2026-07-23)

Unlike Sarah's initial rows, Jennifer's copy should **allude to what the product actually is**, compliantly, rather than staying fully vague ("this", "it"). Use the established de-code substitutes - **"the good stuff"**, **"premium quality"**, **"delivered to my door"** - worked into at least one headline and/or a line in the primary. This is a per-persona instruction Adam gave for Jennifer specifically; check with him before assuming it also applies retroactively to Sarah's sheet.

## 6. HARD RULE - no underage/pre-legal-age nostalgia anchors (M-15b)

**Identical rule to `sarahs-finds-voice.md` §10 - do not relearn this the hard way twice.** Never anchor a nostalgia beat to high school, teen years, back-in-school, college (when implying pre-21 use), when-I-was-young/a-kid, or childhood - these read as coding "I used this before I could legally buy it," a genuine Meta Drugs-policy + youth-appeal (M-15) violation, confirmed by meta-compliance-agent ruling 2026-07-23.

**Compliant substitutes (use these):** adult-legal life-stages ("my twenties", "my first apartment", "early adulthood") or fully age-neutral phrasing ("takes me back", "the good old days", "simpler times"). Jennifer's worked examples below use "takes me back in a good way" / "reminds me of my twenties" - both compliant, both keep the nostalgic warmth without the underage anchor.
